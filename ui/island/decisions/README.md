# Island decisions

Decisions for the desk island subsystem: the mount contract in `ui/island/`, the Vite preset in `ui/vite/island/`, the host loop and its Vue host in `ui/island/host.js` and `ui/island/Island.vue`, and the desk loader in `frappe/public/js/frappe/ui/island/`.

One decision per file. A decision belongs here when it has a rejected alternative that someone will propose again. A platform constraint that explains one line of code stays a comment at that line.

Keep each file to one screen.
