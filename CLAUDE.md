## Agent skills

### Issue tracker

GitHub Issues on upstream `frappe/frappe`. Always pass `-R frappe/frappe`, because origin is a fork with issues disabled. See `docs/agents/issue-tracker.md`.

### Triage labels

The five default roles, except needs-info maps to the existing `need-more-info` label. See `docs/agents/triage-labels.md`.

### Domain docs

Two glossaries, no ADR folder: `frontend/CONTEXT.md` (desk v2 words) and `ui/CONTEXT.md` (List View words). Decisions live in their tickets. See `docs/agents/domain.md`.
